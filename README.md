# منجز

منصة ملف الإنجاز المهني الذكي للمعلم والمعلمة.

## التشغيل

```powershell
powershell -ExecutionPolicy Bypass -File .\start-server.ps1
```

ثم افتح:

```text
http://127.0.0.1:5501/index.html
```

## ما الذي أصبح فعليا؟

- تسجيل الدخول يتم عبر الخادم.
- الإنجازات تحفظ في `data/munjaz-store.json`.
- مواعيد الرزنامة تحفظ في `data/munjaz-store.json`.
- التقارير تقرأ من البيانات المحفوظة وتعرض ملخصات قابلة للطباعة.

## ملاحظة

هذه نسخة تشغيل محلية جاهزة للتطوير والنشر التجريبي. عند تحويلها إلى منصة رسمية لوزارة التربية، الخطوة التالية هي ربطها بقاعدة بيانات وحسابات مستخدمين بصلاحيات.
